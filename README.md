JoinMe 

> Course Project Notice: This repository contains only the frontend (UI/UX prototype) of the JoinMe mobile application built with Flutter. Backend services such as authentication, database integration, real-time messaging, and APIs are not included in this repository.




---

📌 Project Description

JoinMe is a location-based mobile app that helps people create and discover spontaneous nearby activities in real time. It makes it easy to turn free time into shared experiences by connecting individuals for study sessions, sports, and casual hangouts within their local community.
